# Pithom

A Python learning project with basic examples and exercises.

## Contents

- `main.py` - Simple "Hello World" program in Portuguese ("ola mundo")
- `myNoteBool_01.ipynb` - Jupyter notebook with Python class examples

## Getting Started

To run the main program:

```bash
python3 main.py
```
